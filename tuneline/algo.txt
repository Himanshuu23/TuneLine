** LOGIC FOR ADDING MUSIC IN QUEUE ** 
(here, song and video are same same)

- if a song is currently playing then don't touch it in the queue
- highest priority will be of that song - on which highest money has been paid
- if money same next priority would be on the basis of votes
- and next would be on the basis of their position in the queue obviously.

WORKFLOW

- Suppose there's a queue with three songs inside it and one song is already playing, 
then if a new song is added inside the queue with more money than the second one then 
it would come between the current song (i.e. the first one in the queue) and the second
song

- When the song is done playing we would remove the song - make a function which pops the
first element of the queue with time in seconds as parameter and this would be the length
of the song - this function would be called everytime new song gets played.

OPTIMIZED SOLUTION
- using sorted redis sets 
O(logn) -> since insertion is logn whereas in lists it is n , also sorted automatically on the basis of scores and fast retrieval with zrange with scores

Pseudo Code

function addSong(roomCode, music) {
    score = music.money * 1e6 + votes

    redis.zadd(`${roomCode}:queue`, score, JSON.stringify(music))
    return "song added"
}

function getHighestPrioritySong(roomCode) {
    result = redis.zrange(`${roomCode}:queue`, 0, 0)

    return JSON.parse(result[0])
}
